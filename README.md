# Multi Keybinds (Fabric, Minecraft 1.21.11)
Bind extra keys / mouse buttons to any action (up to 3 per action).
Controls screen -> green "+ Multi Keys" button (top-left) -> click "+" next to an action -> press a key.
Saved in config/multikeybinds.json. Normal keybinds are untouched.
Build: push to GitHub, Actions tab -> download "multikeybinds-jar". Or `gradle build` with JDK 21.
